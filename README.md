# Gang Beasts Hunch (MelonLoader)

Garb: tylek odsuniety do tylu, tulow z glowa pochylony do przodu, dluzsze rece.
Efekt jest tylko wizualny (kosci rysowane sa inaczej, fizyka i kolizje zostaja bez zmian), wiec gra dziala normalnie.

1. Wrzuc `GangBeastsHunch.dll` do `Gang Beasts/Mods/`.
2. Uruchom gre. Log: `GangBeastsHunch_log.txt` w folderze gry. Ustawienia: `UserData/MelonPreferences.cfg`.

## Klawisze w grze
F6 wlacz/wylacz, F7 odwroc kierunek (jesli garb jest w zla strone), F8/F9 kat garbu -/+, F10/F11 dlugosc rak -/+.

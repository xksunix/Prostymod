# Gang Beasts Willy 1.0 (MelonLoader, IL2CPP)

Małe, kluskowate pisiorki z jajeczkami w kolorze danej postaci (bez żadnego sexu, czysty głupi humor), które bujają się na sprężynach, plus sikanie z kałużami.

## Instalacja
Wrzuć `GangBeastsWilly.dll` do folderu `Mods` w katalogu gry (`...\Gang Beasts\Mods`) i uruchom grę.

## Działanie
- Każda postać dostaje pisiorka z dwoma jajeczkami. Wszystko jest na sprężynach (jiggle): bujają się przy biegu, skokach i upadkach.
- **K (przytrzymaj)** – wszystkie postacie sikają. Pisiorek się unosi, leci strumień, a kałuże zostają na podłodze i się rozlewają.

## Klawisze
| Klawisz | Działanie |
|---|---|
| K | sikanie (przytrzymaj) |
| F6 | włącz / wyłącz mod |
| F7 / F8 | mniejszy / większy |
| PageUp / PageDown | wyżej / niżej |
| Home / End | dalej od ciała / bliżej |
| F9 | posprzątaj kałuże |
| F10 | odwróć przód (jeśli pisiorek jest z tyłu) |

Ustawienia: `UserData/MelonPreferences.cfg`, sekcja `GBWilly` (`Size`, `ForwardOffset`, `UpOffset`, `JiggleAmount`, `PeeSpeed`, `PeeSpread`, `PeeRate`, `MaxPuddles`).

# Gang Beasts Head Swap (MelonLoader, IL2CPP)

Wszystkie postacie w Gang Beasts dostają głowę z modelu (zamiast oryginalnej). Głowa mruga, a gdy postać krzyczy/śmieje się (jej głos),
otwiera usta. Nic nie atakuje.

Instalacja: `GangBeastsHeadSwap.dll` do folderu `Mods`. Model i tekstura są w środku DLL.

Klawisz **H**: menu - włącz/wyłącz podmianę, rozmiar głowy, obrót twarzy (gdyby była z tyłu lub z boku), zmiana materiału.
Ustawienia: `UserData/MelonPreferences.cfg`, sekcja `GBHeadSwap`.
Jeśli coś nie działa, wyślij `MelonLoader/Latest.log`.
